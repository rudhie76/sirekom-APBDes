💡 Panduan Cepat Sinkronisasi Google Sheets

Aplikasi ini terhubung langsung ke Google Sheets melalui Google Apps Script Web App. Data master desa, nomor rekening, dan riwayat penerbitan surat tersimpan otomatis di Google Drive Anda.

Tempelkan URL Web App yang didapat setelah melakukan "Deploy as Web App" di Google Apps Script.

Langkah Pemasangan Google Apps Script (Hanya 2 Menit):
  1. Buat Google Spreadsheet baru di sheets.new
  2. Klik menu Extensions (Ekstensi) > Apps Script
  3. Salin seluruh kode dari file google_apps_script.gs (klik tombol di bawah)
  4. Hapus kode bawaan di Apps Script, lalu tempelkan kode tersebut dan Simpan (Ctrl+S)
  5. Klik Deploy > New deployment > Pilih jenis Web app
  6. Atur: Execute as: Me dan Who has access: Anyone (Penting agar web dapat mengakses tanpa login)
  7. Salin URL Web App dan tempelkan ke kolom input di atas. Selesai!
